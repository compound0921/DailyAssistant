# 课表样例

放真实导出的课表文件，用于校准正方解析器。

- HTML：登录正方教务 → 课表查询 → 浏览器「另存为」完整网页。
- Excel：课表页「导出」下载的 `.xlsx`。
- 消息总览 / 考试信息：对应页面「另存为」HTML，用于校准自动同步解析器。

命名：`zhengfang-<学校>-<学期>.html` 或 `.xlsx`；真实页面可保留原名。

先删除学号、姓名、班级等个人信息。本目录的 HTML/XLSX 文件只用于本地测试，已在 `.gitignore` 中忽略，不要提交到公开仓库。解析器测试使用 `test/fixtures/` 中的脱敏样例，不依赖本目录。
