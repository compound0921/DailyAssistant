# 学习通接入

## 范围

只读取学习通作业、考试和随堂练习的截止时间，写入本地 Deadline。

- 不做签到、不自动答题、不上传作业、不修改学习通数据。
- 不使用 WebView，也不注入 `xuexitongScript`；该快照只做页面内视频播放，没有数据接口。

## 数据流

```
账号密码 → passport2 登录 → SSO Cookie
                              ↓
      ┌───────────────┼────────────────┐
 gas/taskmsg      课程活动列表     课程作业/考试页
 作业/考试        随堂练习          （回退）
      └───────────────┼────────────────┘
                      ↓
          映射为 Deadline（source=xuexitong）
                      ↓
            按 externalId 合并到本地列表
```

随堂练习通过每门课的 `taskactivelist` 活动列表筛选：`activeType == 42`，
或名称/链接含“随堂练习/练习/exercise”。`mobilelearn` 活动接口必须使用官方客户端
UA，否则返回 `status=0`。再用 `getPPTActiveInfo` 取 `endtime`；没有结束时间时
按默认 1 小时估算。结束时间已过的活动不再导入，同时清理本地已存在的过期随堂练习
（已完成的保留）。

不再限制检查的课程数量。每门课最近一次活动超过 180 天后，后续同步跳过该课程；
从未检测到活动的新课程从首次检查起算 180 天。活动详情请求每次最多 50 次。

原生任务列表失败时，回退到课程列表 + `workList`/`examList` 页面。列表页保留整行文本，只在“截止/结束/到期/至”之后解析日期，避免把发布时间当成截止时间。列表页没有截止时间时，再读取任务详情页的“作答时间/考试时间”，每次同步最多尝试 10 次详情请求；仍解析不到的任务跳过并提示。

## 登录与持久化

- 账号、密码、`ChaoxingSession` 全部写入 `flutter_secure_storage`。
- 打开应用时自动同步；两次自动同步间隔至少 5 分钟。
- Cookie 失效时用保存的密码静默重登一次；失败后进入 30 秒冷却，避免触发风控。
- 验证码、新设备短信验证、弱密码重置不自动处理，只展示说明和验证链接。
- 设置页可一键清除账号、密码和登录态。

## 同步规则

- 原生任务列表用平台任务 ID 作为 `externalId`，回退页面用任务 URL；本地 ID 为 `xxt:<externalId>`。
- 已存在条目更新标题、截止时间、课程名和备注。
- 本地手动勾选的完成状态不会被平台未完成状态覆盖。
- 平台已完成且本地不存在的历史任务不新增。
- 平台不再返回的旧条目保留，不自动删除。

## 依赖

`third_party/flutter_chaoxing` 是 pub.dev 包 `flutter_chaoxing` 0.4.2 的裁剪副本（Apache-2.0）：

- 保留：passport2 登录、只读学生数据接口、相关模型与签名工具。
- 移除：签到服务、人脸签到、验证码求解、设备 UA 伪造、设备 RSA/内嵌私钥、`image` 依赖。

选择内嵌而不是 pub 依赖，是因为上游 `image → archive ^4` 与项目现有 `excel → archive ^3` 冲突。

## 已知限制

- 协议与常量来自官方 Android 7.0.2 客户端，学习通更新后可能失效。
- 首次登录或换网络时可能触发验证码/短信验证，需要人工完成。
- 自动同步失败时保持安静，具体原因需进入学习通页面手动同步查看。
- 尚未用真实账号联调；首次登录请观察完整同步结果。
- 学习通没有公开 API，使用前请确认符合学校与平台规定。
