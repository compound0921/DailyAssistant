# 局域网同步

电脑和手机都能发送或接收。接收是单向全量覆盖，不合并两端记录。

## 使用

1. 两端安装支持局域网同步的版本，连接同一 Wi-Fi、路由器或手机热点。
2. 在要保留数据的设备打开「设置 → 局域网同步 → 发送本机数据」，点击「开启发送」。
3. 复制连接码到另一台设备，在「接收并覆盖」中粘贴，点击「获取发送端数据」。
4. 核对条数，点击「确认覆盖本机数据」，再次确认后替换本机数据。

连接码 10 分钟内有效。切到后台仍保留发送和接收连接，离开局域网同步页时关闭连接；重新开启发送会生成新码。
有多个网卡时，选择与接收端同一局域网的地址。连接码含临时访问密钥，只交给自己的设备。

## 覆盖范围

- 全部课表、当前课表、各课表的作息与学期设置。
- 全部日程，包括完成状态、标签、备注、提醒提前量、置顶与手动顺序。
- 全部考试，包括手动考试、本地修改、恢复默认值、星标和手动顺序。

接收端原有的以上内容全部替换；发送端没有的数据也会删除。空数据会清空相应内容，确认后不能撤销。
旧课表导出口令会清除，避免继续使用覆盖前的缓存口令。

登录账号、密码、Cookie、教务消息、雨课堂缓存、主题外观和设备通知总开关不参与传输，保留接收端自己的值。
接收后按本机通知设置重新排程提醒，取消旧日程的提醒。

## 传输与限制

使用临时随机密钥和 AES-GCM 校验加密的局域网连接，不经过云端。
先完整接收并校验，再确认写入；断开或校验失败不覆盖数据。写入失败尝试恢复覆盖前的数据。
一次快照最多 8 MB、500 份课表、50000 条日程、200 场考试。

同步期间不要离开两端的局域网同步页，可以临时切到其他应用。系统休眠或结束进程仍可能中断连接。
准备数据前会等待已有的平台同步结束，避免旧任务继续写入。
此功能不做自动发现、持续双向同步或常驻后台服务；以后再次同步仍需明确选择发送端和接收端。
平台账号不随业务数据迁移，之后的平台同步使用各设备自己的登录态。

## 无法连接

- 确认连接码完整、未过期，发送端未离开局域网同步页。
- Windows 防火墙提示时允许应用在专用网络通信。
- 校园 Wi-Fi 或访客网络可能禁止设备互访，可改用手机热点。
- 开启 VPN 或虚拟网卡时，检查发送地址是否选中了实际局域网网卡。

## 验证

自动测试覆盖完整数据往返、全量清空、保留本机登录态、错误密钥、连接中断、覆盖确认和取消。
同一台机器的回环连接测试不能证明校园网、防火墙或具体手机的连通性，实际互传仍需两端验收。
