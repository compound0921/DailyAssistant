## 风险与假设

- 正方教务导出格式因版本和学校而异，需要真实文件校准解析器；页面结构改版也会影响自动同步。
- 正方 WebVPN 登录页的加密脚本使用非标准 DES 位序，已按页面脚本移植并用固定向量校验；验证码仍需人工处理。
- 雨课堂、学习通无公开 API；学习通接入基于官方客户端协议还原，只做只读同步，协议可能随平台更新失效，并受平台规则限制。
- 检查更新依赖 GitHub API 和 Release 资产下载；网络不可达或 API 限流时只能提示稍后重试，不提供镜像。
- 本地通知使用系统闹钟与计划通知，不做后台轮询；Android 部分厂商的省电策略可能延迟提醒，需用户在系统设置中放行。通知不可用时只影响提醒，不影响日程数据。
- ICS 订阅需要网络与系统权限，需处理编码和重复导入。
- iOS 无法在当前 Windows 环境构建验证。
