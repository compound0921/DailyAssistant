# 正方教务接入

## 范围

通过学校 WebVPN（`wvpn.qust.edu.cn`）只读访问正方教务：

- 消息总览：`jwglxt/xtgl/index_cxDbsy.html?flag=1`
- 考试信息查询：`jwglxt/kwgl/kscx_cxXsksxxIndex.html?gnmkdm=N358105&layout=default`

不修改、提交或删除教务数据；不自动抓取课表，课表仍使用 HTML/Excel 导入。

## 数据流

```
学号 + 密码
    ↓
WebVPN 统一身份认证（tpass）
    ↓  Cookie
智慧青科门户（i.qust.edu.cn/tp_up）
    ↓
正方 SSO（jwglxt.qust.edu.cn/sso/driotlogin）
    ↓  Cookie
消息/考试页面（空壳，取学年学期、CSRF 和 Referer）
    ↓
POST index_cxDbsy.html?doType=query
POST kscx_cxXsksxxIndex.html?doType=query
    ↓ JSON items
JiaowuMessage / JiaowuExam ──→ 首页消息与考试安排（不写日程）
    ↓
本机快照（SharedPreferences）
```

## 登录流程

1. `GET https://wvpn.qust.edu.cn/login?cas_login=true`，跟随 302 到统一身份认证页。
2. 解析 `form#loginForm` 的 `action`、`lt`、`execution`、`_eventId`。
3. 用登录页同款 `strEnc(学号 + 密码 + lt, '1', '2', '3')` 生成 `rsa`。
4. POST 表单字段：`rsa`、`ul`（学号长度）、`pl`（密码长度）、`lt`、`execution`、`_eventId=submit`。
5. 手动跟随重定向并收集 `Set-Cookie`；成功后 Cookie 用于访问教务页面。

`lib/jiaowu/jiaowu_des.dart` 是登录页 `des.js` 的按位移植。该脚本的密钥位序与标准 DES 实现不同，不能用通用 DES 库替代；`test/jiaowu_des_test.dart` 用 JS 生成的固定向量校验。

出现验证码时不做破解，只提示人工在浏览器完成登录。

## 解析规则

- 页面本身是空壳，数据通过 `?doType=query` 接口异步加载；同步时直接 POST 查询接口。
- 消息接口返回 `items`：`xxbt`（标题）、`xxnr`（内容）、`jsmc/jsdm`（角色）、`cjsj`（时间）、`id/zjxx`（标识）；按时间倒序。
- 考试接口返回 `items`：`kcmc`、`kssj`、`cdmc`、`cdxqmc`、`ksmc`、`ksfs`、`kch`、`jxbmc` 等；不保存学号、姓名、班级成员等个人字段。
- 考试查询的学年/学期从页面 `#cx_xnm`、`#cx_xqm` 的选中项读取；同时带上 `gnmkdm=N358105`、`csrftoken` 和 `Referer`。
- 考试时间兼容 `2026-10-31(18:00-19:40)` 和 `2026-11-05 14:30-16:30`；缺少结束时间时按开始时间 + 2 小时估算。
- HTML 解析器保留为兜底，主要用于 `docs/samples/` 的已保存页面和测试。
- 消息只取查询接口第一页（当前 `showCount=10`），不继续翻页；考试取当前查询页。

## 存储与同步

- 学号、密码、WebVPN Cookie 写入 `flutter_secure_storage`。
- 消息与考试快照写入 `shared_preferences`（`jiaowu_snapshot_v1`）。
- 启动、下拉刷新、手动同步；两次自动同步间隔至少 5 分钟。
- Cookie 失效时用保存的密码静默重登一次；失败后进入 30 秒冷却。
- 清除登录数据会同时删除账号、密码、Cookie 和快照。

## 考试安排（不写日程）

- 考试只在首页“考试安排”和教务页展示，不转换成日程条目。
- 教务快照保留本学期全部考试，包括已过期考试；教务页全部展示。
- 首页未过期考试自动显示，最近 3 场，剩余时间按四档着色：7 天以上蓝色、4-7 天橙色、1-3 天深橙、今天/进行中红色。
- 过期考试默认不上首页；在教务页点星标后保留在首页。首页标题旁“添加”可手动添加考试。
- `externalId` 由学年、学期、课程代码、考试名称、教学班组成，仅用于页面内去重和排序；手动考试使用 `manual:` 前缀。
- 首页考试行支持左滑“编辑 / 删除”；编辑页可修改课程、考试名称、起止时间、地点、校区、类型和备注。
- 编辑只写本机快照；同步时保留已编辑字段，并把可恢复的默认值更新为本次教务结果。已编辑考试可在编辑页单场“恢复默认”。
- 教务本次未返回但本地编辑过或手动添加的考试继续保留；未编辑且未返回的考试移除。
- 手动删除只移除本机条目；下次同步时，如果教务仍返回，会重新出现。
- 清除教务登录数据会删除同步考试，但保留手动添加的考试。
- 旧版本自动生成的 `source=jiaowu` 考试日程会在启动时清理；手动和学习通日程不受影响。
- 学习通同步的作业/考试仍按原逻辑进入日程。

## 消息驱动课表调整

教务消息会叠加到周课表和首页“今天”，不修改导入的原始课表数据。

- `调课提醒`：原时间标记“调走”（斜线阴影），新时间标记“调课”（2px 蓝色边框）。
- `补课提醒`：新时间标记“补课”；消息没写地点时使用课程原地点。
- `停课提醒`：原时间标记“停课”（斜线阴影）。
- `换教师提醒` 和考试通知忽略，不参与课表调整。
- 解析 `第N周`/`第N-M周`、`星期X`、`第N-M节`，按当前课表作息换算成分钟；发布时间明显早于当前学期或超出学期范围的消息忽略。
- 课程名先去掉 `调`、`★`、`○` 等标记再匹配；匹配不到时生成独立叠加块。
- 同一时段同时出现“调走”和“调来”时，以调来的课为准，避免一格显示两个冲突块。
- 首页“今天/下一节”使用同一份有效课程结果；停课课程用删除线和角标表示，调课/补课用角标表示。

## 已知限制

- WebVPN 登录页、加密脚本、智慧青科门户、正方 SSO 或查询接口改版后可能失效。
- 验证码、账号锁定等需要人工处理。
- 消息和考试只取查询接口第一页；更多数据需要后续增加 `page` 翻页请求。
- 学校 WebVPN 的加密主机段、门户/SSO 路径写在客户端常量中；学校调整入口后需要更新。
- 真实样例含姓名、学号等个人信息，只用于本地校准，不提交到仓库。
