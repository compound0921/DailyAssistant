# 测试环境

## Android 模拟器

已配置：

- SDK：`D:\Android\Sdk`
- AVD：`daily_assistant_phone`（Pixel 7，Android 16 / API 36）
- 环境变量：`ANDROID_HOME`、`ANDROID_SDK_ROOT`、`ANDROID_AVD_HOME`

启动并运行：

```bash
flutter emulators --launch daily_assistant_phone
flutter devices
flutter run -d emulator-5554
```

热重载按 `r`，热重启按 `R`。设备 ID 以 `flutter devices` 为准。

新开终端如果看不到 AVD，重启编辑器/终端，或先设置：

```bash
set ANDROID_AVD_HOME=D:\Android\avd
```

首次构建已安装 NDK 28.2 和 CMake 3.22.1。项目位于 D:、Pub 缓存在 C:，Gradle 已关闭 Kotlin 增量编译（`android/gradle.properties`）以避开跨盘路径错误。

模拟器 `Download` 目录已放入 `课表样例.html` 和 `sample.ics`，可直接在应用内导入测试。

构建 APK：

```bash
flutter build apk --debug
```

产物：`build\app\outputs\flutter-apk\app-debug.apk`。

手动启动模拟器：

```bash
D:\Android\Sdk\emulator\emulator.exe -avd daily_assistant_phone -gpu swiftshader_indirect
```

`-gpu host` 在当前 NVIDIA 驱动下可能因 GPU 错误退出；`swiftshader_indirect` 更稳定。也可以直接双击项目根目录的 `start_android.bat`，它会启动模拟器并运行应用。

`maven.google.com` 在当前网络超时，Gradle 已改用 Aliyun 镜像，配置见 `android/settings.gradle.kts` 和 `android/build.gradle.kts`。

## iPad 尺寸预览

Windows 无法运行 iPadOS 模拟器。用 Flutter Web + Edge 验证布局：

```bash
flutter run -d edge
```

Edge 中按 `Ctrl+Shift+M` 打开设备工具栏，选 iPad Pro 11"（834×1194）或 iPad Pro 12.9"（1024×1366）。

限制：

- 这是 Web 布局预览，不是 iPadOS Safari 或触控环境。
- 真正 iPadOS 测试需要 macOS + Xcode 模拟器，或云 Mac 构建后在真机/云设备上测。
