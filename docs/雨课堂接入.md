# 雨课堂接入

## 范围

只读扫码登录、会话检查、课程列表，以及每门课学习日志里的「课件」「试卷」两栏。不写日程，不签到、不答题、不提交。

## 数据流

```
二维码 → 微信/雨豆扫码 → sessionid
                         ↓
                  basic-info（用户/会话）
                         ↓
                  courses/list（课程列表）
                         ↓
              logs/learn（课件/试卷条目）
                         ↓
              v/exam/cover（试卷详情）
```

## 登录

1. `GET /api/v3/user/login/app-web-pre-info` → `data.qrContent`、`data.token`，token 约 5 分钟。
2. 应用内渲染 `qrContent`，用微信或雨豆 App 扫码。
3. `POST /api/v3/user/login/app-web-login`，body `{"token":"…"}`，长轮询；确认后下发 `Set-Cookie: sessionid`。

域名固定为 `qust.yuketang.cn`。标准版、长江版、荷塘版的会话互不通用。

## 会话

- 只保存 `sessionid`、`csrftoken` 等白名单 Cookie，存 `flutter_secure_storage`。
- 用户与课程快照存 `SharedPreferences`，不写入安全存储。
- 没有续期接口。第三方实测约 24 小时失效，失效后重新扫码。
- 账号密码登录要过腾讯/hCaptcha 图形验证码，不做静默重登。

## 接口

- 用户：`GET /api/v3/user/basic-info`
- 课程：`GET /v2/api/web/courses/list?identity=2`
- 学习日志：`GET /v2/api/web/logs/learn/{classroom_id}?page=0&offset=200&sort=-1&actype=-1`
- 试卷详情：`GET /v/exam/cover?exam_id={leaf_type_id}&classroom_id={cid}&sku_id={sku_id}`

请求头带 `xtbz: ykt`、桌面 Chrome UA 和 `Referer: https://qust.yuketang.cn/web`。

会话失效特征：HTTP 401/403、`errcode=401000`、`code=50000`、`error_code=401000`。

## 学习日志

- `type=14` 归入课件，取标题和 `create_time`。
- 试卷：荷塘版 `type=20`；标准版可能是 `type=5`，用 `content` 是否带 `leaf_type_id`/`exam_id`/`sku_id`/`score_d` 区分投票。
- 试卷截止先用 `content.score_d`；详情接口返回题数、总分、开始/截止、提交状态和得分。
- 详情逐条串行读取；单条失败只标记该条，不影响其他人。
- 课件不展开幻灯片，试卷不读题目正文。

## 边界

- 旁听课程 `role=6` 仍显示；后续截止同步应跳过。
- 课件/试卷只读展示已接入；写入日程待后续。
- 平台无公开 API，改版可能失效。
- 不保存账号密码，不触碰学校统一认证。

## 验证

1. 点“扫码登录”，用微信或雨豆扫码确认。
2. 页面显示姓名、学校与课程数。
3. 点课程进入详情，确认「课件」「试卷」数量和条目。
4. 试卷显示题数、总分、开始/截止、状态；有分数时显示得分。
5. 重启应用后登录态仍在，点“刷新课程”能更新列表。
6. 会话失效后，页面提示重新扫码。
